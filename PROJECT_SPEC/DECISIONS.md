# STUDYBOT DECISIONS

## D-001 — Product identity
StudyBot is a DAU student learning assistant, not a generic chatbot.

## D-002 — Current target
Focus on Information Technology students, especially 24CT1 and 24CT2.

## D-003 — Learning-first scope
Learning materials, learning questions, knowledge explanations and related study support have priority.

## D-004 — Current AI
Keep PyTorch + Bag of Words + Neural Network + Intent Classification as the main AI.

## D-005 — AI roadmap
Embedding/Semantic Search → PDF → RAG → advanced RAG.

These are not automatically considered implemented.

## D-006 — Context
Allow approximately 10–15 recent relevant questions; do not carry unrelated context.

## D-007 — Data integrity
Do not invent school information. Mutable information should carry source/update status where possible.

## D-008 — Source display
Where appropriate, chatbot answers should expose source and update information.

## D-009 — Scope control
Unsolicited features are not implemented. Ideas belong in the roadmap/task queue.

## D-010 — Change approval
Major architecture, database, authentication/security, external services or main-AI changes require project-owner approval.

## D-011 — Product quality
The project is intended to be developed seriously toward deployable-product quality, not merely to satisfy a classroom checklist.

## D-012 — Source of truth
When documents conflict, do not silently reconcile them. Inspect source and ask the project owner to approve the decision.
