## Architecture Findings
- Tổ chức theo mô hình Flask (Web app) ghép với hệ thống nhúng PyTorch model (AI).
- Flask khởi tạo DB và cấu hình Authentication; API gọi trực tiếp AI model.
- App phụ thuộc nặng vào `app/routes.py` xử lý chung toàn bộ tác vụ.

## Dependency Findings
- Modules kết nối trực tiếp với Database theo chuẩn SQLAlchemy (`app/models.py`).
- Model PyTorch sử dụng `torch`, `nltk`, `numpy` và kết nối với data JSON (`data/`).
- `requirements.txt` không dư thừa.

## Database Findings
- SQLite databases nằm gọn trong thư mục `instance/`.
- Có sự hiện diện của một file db legacy `framework/src/database/db.py` hoàn toàn không có tương tác nào trong toàn bộ ứng dụng (sử dụng `sqlite3` driver thuần).

## Authentication Findings
- Logic xử lý an toàn và gom cụm tại `app/auth.py` bằng Flask-Login. Cơ chế băm Werkzeug. 
- Không phát hiện trùng lặp authentication rules.

## Route Findings

- Toàn bộ đều tập trung tại file `app/routes.py`. File không có dead routes, tuy nhiên thiết kế này khá cồng kềnh.
