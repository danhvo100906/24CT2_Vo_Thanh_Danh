# INSPECT PROJECT

## Goal
Understand the real state before implementation.

## Procedure
1. Read project specification.
2. Inspect repository structure.
3. Identify entry points.
4. Inspect AI, database, web, data and tests.
5. Run existing checks when possible.
6. Compare source against documented status.
7. Record:
   - implemented;
   - partially implemented;
   - missing;
   - broken;
   - claimed but unverified;
   - out of scope.
8. Do not modify code unless explicitly requested.
