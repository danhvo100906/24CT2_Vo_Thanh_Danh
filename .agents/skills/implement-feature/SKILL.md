# IMPLEMENT FEATURE

## Goal
Implement one approved feature without scope creep.

## Procedure
1. Read `AGENTS.md` and project specification.
2. Read `CURRENT_STATUS.md`, `DECISIONS.md`, `TASK_QUEUE.md`.
3. Identify exact acceptance criteria.
4. Inspect relevant source/tests.
5. List affected files.
6. Detect architecture/schema/dependency changes.
7. If an approval gate is triggered, stop and ask.
8. Implement the smallest safe change.
9. Add/update tests.
10. Run tests.
11. Review git diff.
12. Update status/docs if required.
13. Report result and evidence.

## Never
- add unrelated features;
- rewrite unrelated code;
- claim untested behavior;
- silently change project direction.
