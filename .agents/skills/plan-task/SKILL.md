# PLAN TASK — CODEX

## Goal
Convert one user request into an executable, bounded StudyBot task.

## Procedure
1. Read AGENTS.md, project specification, decisions and current status.
2. Inspect relevant source and tests.
3. Identify objective and current behavior.
4. Define scope and explicit non-scope.
5. List likely affected files without inventing files.
6. Write measurable requirements and acceptance criteria.
7. Define testing requirements.
8. Check approval gates.
9. Write `PROJECT_SPEC/HANDOFF/CURRENT_TASK.md`.
10. Write `PROJECT_SPEC/HANDOFF/CODEX_PLAN.md`.
11. Set task state to `READY_FOR_ANTIGRAVITY`.

Do not implement while performing this skill unless explicitly instructed by the user.
