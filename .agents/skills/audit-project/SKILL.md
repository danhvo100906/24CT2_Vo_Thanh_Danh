# AUDIT PROJECT

## Goal
Audit StudyBot against the approved specification.

Check:
- scope;
- architecture;
- AI;
- retrieval;
- data;
- database;
- authentication;
- admin;
- tests;
- UML/documentation;
- security;
- stale/unsupported claims.

Classify every finding:
P0 Critical / P1 High / P2 Medium / P3 Low.

Do not fix findings automatically unless requested.
Produce evidence and recommended action.
