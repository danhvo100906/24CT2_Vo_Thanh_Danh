# DATA AND SOURCE RULES
Do not invent school data.

For mutable information such as tuition, regulations, procedures, schedules or notices:
- store/source the origin where possible;
- store update time/status where applicable;
- flag stale data;
- never present known-old information as current.

Prefer:
1. official DAU information;
2. verified project knowledge;
3. approved academic materials;
4. trusted external sources when explicitly supported.

If data cannot be verified, say so.
