# PROJECT SCOPE RULES
StudyBot currently focuses on learning support and study-material retrieval for DAU Information Technology students, especially 24CT1/24CT2.

Do not add unrelated features.

Classify discoveries as:
- CURRENT TASK
- REQUIRED DEPENDENCY
- BUG FIX
- TECHNICAL NECESSITY
- FUTURE IDEA
- OUT OF SCOPE

Only the first four may be implemented automatically.

FUTURE IDEA and OUT OF SCOPE must not be implemented.
